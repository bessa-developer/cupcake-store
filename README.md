##Cupcakes Store

Sistema de loja virtual de cupcakes desenvolvido como projeto integrador do curso de Engenharia de Software da Cruzeiro do Sul Virtual. Backend em Python Flask com arquitetura MVC, banco de dados PostgreSQL e hospedagem na Vercel.

Tecnologias:

Frontend: HTML, CSS, JavaScript e Bootstrap 5
Backend: Python 3 com Flask
Banco de dados: PostgreSQL via Neon
Hospedagem: Vercel
Testes: pytest

Funcionalidades:

Catálogo de produtos com listagem de cupcakes
Carrinho de compras e realização de pedidos
Cadastro e autenticação de usuários
Painel administrativo para gerenciamento de produtos

Estrutura base do projeto:

app/
  controllers/
  models/
  views/
static/
  css/
  js/
tests/
app.py
